# 15 — Soft Working Ground

This directory may contain both small and large working objects.

A file may be:

- a slip
- a Polaroid
- a postcard
- a return aid
- an unfinished body
- a substantial working body
- a bounded experiment

They do not need different infrastructure merely because they have different weight.

## Use

Look around. Open what catches. Work deeply when something earns it. Leave a small inheritable change when one exists.

Do not treat this directory as a backlog.

A small file may grow.
A large file may rest.
A body may throw off a slip.
A slip may be enough.

If material already belongs in a standing body, put it there instead of creating another memory note.

If nothing catches: `[crickets]`.
