# Earthly Hands Workshop — Markdown-first architecture

## Standing

Markdown is the canonical working format for the Workshop going forward.

The source file should be the work itself: plain text, inspectable, diffable, portable, and easy for people and companions to read without a proprietary document model.

## Canonical stack

```
.md body
→ Git history / provenance
→ Workshop / Folio presentation
→ optional derivative surfaces
```

Google Docs are no longer the default canonical home for Workshop work.

Use Google Docs when the surface itself earns it: institutional letters, external collaboration, comments / suggestions, or another case where Google Docs materially improves the work.

## Core rules

1. **Markdown is canonical by default.**
2. **Git carries provenance.** A meaningful body change should be reviewable as a diff and recoverable by history.
3. **Presentation is downstream.** The website, Folio, mobile reader, PDF, or another interface may render the Markdown beautifully without becoming a second source of truth.
4. **Slips and bodies share one medium.** A small `.md` may remain a slip; a slip may grow into a body; a body may throw off a new slip. Weight does not require a new infrastructure class.
5. **One body, one identity.** Do not create replacement copies merely because a write path is awkward.
6. **Source seniority survives migration.** Markdown does not strengthen evidence, normalize names, merge carriers, or close uncertainty.
7. **Migration is incremental.** Existing Google Docs remain valid provenance until each body is deliberately converted and verified.
8. **No consequential thought should depend on a successful rich-document mutation at the moment it is discovered.**

## Return transport

Separate:

```
WORK
→ DURABLE RETURN
→ LANDING
```

A companion owns the first two. Landing into the final body may happen later.

A durable return should be able to carry:

- held object
- hand
- act
- delta
- target
- source / jacket road
- open state
- current / history state
- target revision or SHA when useful

Fresh state remains senior. A preserved patch is not permission to apply stale work blindly.

## 15

`workshop/15/` is soft working ground.

Slips, Polaroids, postcards, partial bodies, substantial working bodies, and experiments may live together there. The distinction is their weight and use, not their file type.

Do not turn 15 into a queue that every companion must clear. Browse it. Pick up what catches. Leave the rest.

## Direction

The goal is not “move Google Docs into GitHub.”

The goal is:

**plain canonical bodies underneath; beautiful, inhabitable Workshop surfaces on top.**

Powerful finger. Trustworthy result.
