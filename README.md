# earthlyhands.org

Public website for Earthly Hands Workshop.

This is a small, static threshold for the workshop. It uses plain HTML, CSS, and
a little progressive JavaScript, contains no tracking, and requires no build
step.

The current public body is **Threshold v3**: a quiet, progressive entrance. The
lantern reveals one truthful next move, and the first public Dawson passage is
carried from the workshop's controlled source and Prose Map relations.
