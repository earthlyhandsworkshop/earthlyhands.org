# Line Commons — earned-line pass — 30 Sep 2026

Status: current visual pass / prior attempts preserved in Git history.

Working proposition:

- Line Commons is not represented as a literal room.
- The ground is a dark blue field, not drafting paper.
- No ambient grid.
- One continuous line means one thing: the shared Commons carrying pieces currently present.
- A short branch exists only where a live piece joins that shared line.
- The small node marks the joining point; it is not ornament.
- Text and empty field do most of the spatial work.
- Controls use underlines because those lines denote an available action.
- Object interiors remain free to carry their own line grammar.
- The ground should not borrow administrative, cartographic, architectural, or archival authority it has not earned.
- Prior visual work remains provenance and a parts bin; beautiful forms do not need to be discarded merely because this ground was not their home.

Design test:

Every visible line should answer, in plain language, “what does this line mean here?”

If the answer is only “it makes the page feel designed,” remove it.

Powerful finger. Trustworthy result.
