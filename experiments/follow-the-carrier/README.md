# Follow the Carrier — first mechanic specimen

**Status:** active public-ground experiment / source bindings intentionally incomplete  
**Public path:** `/experiments/follow-the-carrier/`  
**Scope:** mechanics only; this prototype does not replace governed source jackets or the MCR 879 listening cut.

## Core law

**Reading earns pieces. Sources earn connections.**

The prototype tests whether a visitor can learn documentary reasoning by play:

- a person can open a documentary neighborhood;
- a historical object can appear without entering the active case;
- a family-memory relation can remain visibly different from an administrative carrier;
- same-name or near-name occurrences can remain separate;
- a name can travel farther than a person can speak;
- case closure need not erase the field.

## Three states

**EXISTS** — controlled enough to appear.  
**CARRIED** — a source earns movement or relation into another body.  
**OPERATIVE** — a source earns administrative use or reliance.

Presence is not carriage. Carriage is not reliance.
