## What this tests

One narrow question:

> Can documentary boundary state be carried by page behavior before explanatory prose has to name it?

The specimen uses one controlled provider turn from `Bell Wash.pdf`:

- provider p.57 remains inside the same `M. C. R. 5168.` / `COPY.` notice to `Callie Bell,` / `Ardmore, Indian Territory.`;
- `Registered.` changes function without creating a new document;
- `Encl. M.C.R. 5156.` names an object but does not prove the physical enclosure is present, carried, delivered, or received;
- provider p.58 is a hard reset into a separate handwritten genealogy-chart face.

The visitor may toggle seam labels on and off. The experiment succeeds only if the continuity / open endpoint / hard reset remain intelligible when the labels are hidden.

## Source brakes

- Same provider sequence does not mean same documentary object.
- Same page does not mean same function.
- A pointer does not become its referent.
- A named enclosure does not establish physical survival, carriage, dispatch, delivery, or receipt.
- The p.58 chart is chart representation, not witness speech or independently verified genealogy.
- `Robert Bell`, `Susie Bell`, and `Wash Bell` remain source-local occurrences; this specimen makes no outward identity join.
- Chart maker, compilation date, and source basis remain open.
- The simplified drawn chart is an interaction specimen, not a replacement source representation.

## Porchlight's question back to the workshop

When the labels are hidden, do the three states still read differently?

1. continuation;
2. missing / named-but-not-held endpoint;
3. hard source reset.

If not, change or discard the experiment rather than explaining it harder.
