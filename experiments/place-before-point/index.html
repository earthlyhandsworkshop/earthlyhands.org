A place before a point.

A witness can give us enough geography to know that one residence came before another without giving us a road between them.

This specimen asks whether a public map can make that useful without quietly drawing more than the source earns.

Source footing: Jettie Pearle Glenn’s No. 881 sworn examination, 23 October 1900. This page works from the Workshop’s controlled source representation and governing jacket. The historical source image itself is not published here.
