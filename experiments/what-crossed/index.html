The experiment is not “can you get the right answer?”

It asks whether a public interface can make minimal transfer feel like an ordinary action: carry the relation and its return path; leave behind the stronger property that has not been earned.

If this mechanic feels like a quiz, it has probably not gone far enough. If “holding something back” begins to feel like a successful move rather than a penalty, the experiment is teaching us something.
