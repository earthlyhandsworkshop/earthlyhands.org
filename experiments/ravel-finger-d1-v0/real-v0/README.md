# Ravel real-source v0 — 1826 refusal and recast

This is a bounded, private source specimen for Ravel. It carries two passages from the November 1826 Choctaw negotiations as represented in the MDAH commissioners' journal:

1. the Council reply says that many things could be done to please the President, but `we / Cannot Consent to Part with our Country`;
2. the commissioners' next talk says, `in / substance that you are determined to do nothing`, then acknowledges `the / various reasons that determined you to decline his proposals`.

The pair holds one question: what changes when a bounded refusal to part with country is recast as total inaction?
